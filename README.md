# Brazil E-Commerce Analytics Project

## Project Overview

This project analyzes the Brazilian E-Commerce Public Dataset (Olist) using Data Engineering and Analytics concepts.

The objective is to build an end-to-end analytics solution from raw data ingestion to business reporting and CI/CD automation.
